# KewuToolbox VSCode Bridge 版本兼容表

插件版本和 KewuToolbox 主程序版本不要求同步。只有插件代码、协议字段或兼容范围发生变化时，才需要提升插件版本。

| 插件版本 | 兼容 KewuToolbox 版本 | 协议版本 | 说明 |
| --- | --- | --- | --- |
| 1.0.4 | >=1.0.2 <2.0.0 | 1.0 | 与 1.0.3 功能一致；仅随 KewuToolbox v1.0.4 Release 重新打包发布。 |
| 1.0.3 | >=1.0.2 <2.0.0 | 1.0 | 兼容统一插件桥接、黑白名单匹配和 VS Code 工作区维度归并。 |
| 1.0.2 | >=1.0.2 <2.0.0 | 1.0 | 兼容 VS Code 工作区对象上报和原生 `code.exe` 窗口抑制。 |

维护规则：

- 不要因为 KewuToolbox 主程序发新版本就自动提升插件版本。
- 如果插件协议字段、上报口径、兼容范围或安装方式发生变化，才提升插件版本。
- 每次提升插件版本时，必须在本表最上方新增一行，并写明兼容的 KewuToolbox 版本范围。
