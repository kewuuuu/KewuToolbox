# 更新记录

本文档记录近期功能调整、数据口径修复和兼容性变更。

## 当前未发布改动

### 数据存储
- 主程序数据存储升级为 SQLite，默认数据库文件为 `kewu-toolbox.sqlite`。
- 焦点时间线、进程时间线和键鼠时间桶进入独立 SQLite 表，并建立时间索引；设置、待办、番茄钟等小型状态写入 SQLite 的配置片段表。
- 启动时如果当前数据目录没有 SQLite 数据但存在旧版 `app-state.json` 或分片 JSON，会自动迁移并保留旧文件。
- 设置页新增“数据库”子页面，可查看 SQLite 路径、文件大小、记录数量，并手动执行旧 JSON 到 SQLite 的迁移；该迁移入口计划只保留一个大版本。
- 因主存储格式从 JSON 切换为 SQLite，主程序版本升级到 `2.0.0`。

### 键鼠统计
- 新增全局键鼠采集能力，按当前焦点窗口记录按键次数、鼠标点击、滚轮滚动和鼠标移动距离。
- 键鼠统计合并到“数据统计”页面，作为“键鼠数据”子页面展示，包含指标卡、窗口排行、窗口占比、时间趋势和窗口明细表。
- 键鼠数据与原有窗口识别、记录阈值和白名单归并逻辑共用同一套 `classificationKey`。
- 未达到记录阈值的窗口只在内存中缓存键鼠活动，达到阈值后才写入；短暂临时窗口不会污染统计。
- 只保存聚合数量和移动距离，不保存输入内容、具体按键文本、鼠标坐标或点击位置。
- 键鼠累计数据和 10 分钟时间桶写入 SQLite，不再新增独立键鼠 JSON 数据文件。

### 自动更新
- 修复从旧版本更新时，下载临时文件仍使用旧 exe 文件名的问题；现在优先使用 Release 资产名生成 `.download` 文件。
- 更新脚本会等待目标 exe 解锁后再备份和替换，避免 Electron 子进程尚未退出导致替换失败。
- 说明：如果软件安装在受保护目录，仍可能需要管理员权限；如果同目录能写入 `.download`，通常不是目录写权限问题。

### 插件版本策略
- 插件版本与 KewuToolbox 主程序版本解耦，后续不再因为主程序发布新版本就自动提升插件版本。
- 官方浏览器插件和 VS Code 插件新增 `COMPATIBILITY.md` 版本兼容表。
- 插件接入规范新增强制要求：每个插件必须维护版本兼容表，并推荐在 `plugin.compatibility` 元信息中上报兼容范围。
- 桌面端会保存插件上报的 `compatibility` 数组，供后续展示或兼容校验使用。

### 数据统计与记录口径
- 数据统计页面整合为“焦点数据 / 键鼠数据”两个子页面，并共用同一个时间段选择器。
- 时间段选择器支持起止日期输入、双日历选择、今日、历史所有、最近一周和最近一月快捷项，并在日历中弱化无数据日期。
- 原顶部全局“按性质 / 按窗口”切换移入每个可切换图表的右上角，各图表可以独立选择显示口径。
- 进程时间线和焦点时间线按“记录阈值”忽略短空隙：同一对象短暂切走或短暂关闭后回到同一对象，空隙未超过阈值时按连续时长统计。
- 移除时间线中“合并 N 段”的显示字段，避免把数据层连续口径误描述为 UI 层合并。
- 修复短暂关闭/短暂离焦后回到同一对象时，聚合统计的可见时长、焦点时长、最长连续焦点时长少算的问题。
- 数据统计页的性质视图会列出全部固定性质，窗口占比和排行不再截断为前 10/12 项，进程较多时可滚动查看全部对象。
- 近 14 天趋势图改为多折线：始终显示总聚焦时长，并按当前显示模式追加每个性质或窗口的聚焦时长。
- 设置页新增“数据统计窗口数量 n”，窗口模式下占比、排行、小时活动、趋势和最近时间线会按最高或最近的 n 项展示，默认 10。
- 专注事项“今日累计焦点时长”改用统一统计读取模型，和数据统计页保持同一口径。

### 白名单与插件
- 浏览器插件和 VS Code 插件的白名单记录键统一为 `process-whitelist|规则ID`。
- 桌面端兼容旧插件的 `plugin-whitelist|规则ID`，会自动转换为 `process-whitelist|规则ID`。
- 插件协议新增 `focusedClassificationKeys`，支持同一个插件对象同时命中多条白名单并重复计入焦点时长。
- 白名单/黑名单匹配增加 `www.` 和根路径 `/` 变体，减少复制网址时因为格式差异导致匹配失败。
- 设置页新增“按白名单归并记录”按钮，可按当前白名单重算已有历史记录、统计、时间线、标签绑定、专注事项窗口组和当前运行缓存。

### 页面状态保留
- 设置页未提交输入、待办创建表单、专注事项弹窗、数据统计筛选、进程标签编辑输入会在切换页面后保留。
- 待办详情心得改为输入即写入数据，避免切页前自动保存定时器未执行导致内容丢失。
- 删除确认、批量删除选择、拖拽状态等危险或瞬时交互状态不做跨页面保留。

### 更新与发布
- 设置页新增“更新”页面，可打开 GitHub 仓库首页、检查 GitHub Releases 最新版本，并在存在便携版 exe 与 `.sha256` 时启动自动更新。
- 便携版自动更新改为主程序先下载新版 exe 与 `.sha256` 并显示进度，校验成功后再生成/调用 `KewuToolboxUpdater.cmd` 和 `KewuToolboxUpdater.ps1` 完成关闭、替换和重启。
- `build-deliver.ps1` 会为交付文件生成 `.sha256`。
- 新增 GitHub Actions 自动发布工作流：推送 `main` 后构建交付产物，并按 `package.json` 版本创建或覆盖同版本 Release 资产。

### 仓库与默认状态
- 将 `src/data/mockData.ts` 更名为 `src/data/initialState.ts`，避免把默认空状态误解为假数据。
- 修正 `.gitignore` 中 `data` 的忽略范围为 `/data/`，避免误忽略 `src/data/` 源码目录。
