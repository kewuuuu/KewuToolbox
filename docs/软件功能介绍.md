# 软件功能介绍

本节按页面拆分，逐项说明“做什么、怎么用、边界规则”。

## 1. 进程管理

### 1.1 历史记录
- 展示所有已经达到记录阈值的窗口/标签统计数据（总可见时长、焦点时长、最后焦点时间）。
- 支持按列排序：名称、类型、进程、分类、总可见时长、焦点时长、最后焦点时间。
- 字符串按拼音字典序比较；时长默认降序；最后焦点时间默认从近到远。
- 支持分类标记（学习/娱乐/社交/休息/其他），分类写入本地并在下次识别到同一 `classificationKey` 时继续沿用。
- 支持按“标签”收纳历史数据（有标签的会形成可展开组，显示标签汇总时长与最近出现时间）。
- 每行支持“屏蔽”按钮：点击后会把该对象写入“进程黑名单”。

### 1.2 当前进程
- 只显示“当前仍在打开”的进程/窗口对象。
- 字段与历史记录一致，并额外支持直接分配“标签”。
- 每行支持“屏蔽”按钮，行为与历史记录一致。
- 关闭的窗口会自动从该页消失。

### 1.3 删除记录模式
- 点击右上角“删除记录”后进入勾选模式。
- 表头复选框为“全选/反选”逻辑（再次点击会对当前列表做反选）。
- 再点“确认删除”会删除选中的监控记录（包含 profile/session/stat/tag-assignment 关联项）。

### 1.4 标签管理
- 新增标签：输入名称后按回车或“确认”创建；名称为空则取消创建。
- 编辑标签：支持改名，回车确认。
- 删除标签：删除后会移除该标签的分配关系与标签统计。

### 1.5 系统事件
- 自动记录并展示：启动、挂起、恢复、锁屏、解锁、关机。
- 每条事件附带时间戳与颜色标记，供统计页时间线联动查看。

### 1.6 识别调试
- 展示当前焦点对象的识别结果（显示名、键值、类型、进程、域名、分类）。
- 展示焦点原始对象 JSON，便于排查识别问题。

### 1.7 窗口识别规则（关键）
- 桌面会被识别为独立对象（`Desktop`），默认分类为“休息”。
- 软件内置一条默认黑名单：`AppWindow + explorer.exe`，用于默认忽略文件管理器窗口。
- 该默认黑名单不是硬编码强制忽略：可在“设置 > 通用配置 > 进程黑名单”中手动删除或修改，清空数据后会恢复默认项。
- 浏览器原生窗口标题（如“和另外 N 个页面...”）会被忽略，不再作为独立记录源。
- 支持统一插件桥接：插件可上报“替代记录 + 抑制规则”，用于替换桌面端原生进程识别结果。
- 浏览器插件默认会把浏览器进程窗口替换为插件上报的标签对象。
- 白名单规则采用统一匹配模型（名称/类型/进程通配），命中后会归并到白名单命名项，原对象不再单独记录。
- 窗口记录阈值可配置（默认 60 秒）：短于阈值的临时窗口不会写入历史统计。
- 同一对象短暂切走或短暂关闭后又回到该对象，若空隙未超过记录阈值，会在数据层忽略该空隙并按连续时长统计。

## 2. 专注（番茄钟 + 专注事项）

### 2.1 专注事项
- 可创建“专注事项”卡片，每项包含：
  - 标题
  - 默认时长（分钟）
  - 窗口组（从已识别窗口中多选）
- 编辑事项时新增“已添加进程/规则”列表，可直接删除已有项。
- 支持手动添加窗口匹配规则（名称/类型/进程，支持通配符）。
- 规则匹配含义：
  - 留空字段表示该字段“匹配全部”。
  - 采用统一匹配逻辑，不区分“网址规则”和“进程规则”。
  - 已填写的字段需同时匹配。
- 事项卡片显示该事项窗口组“今日累计焦点时长”。
- 支持编辑、删除、加入专注队列。
- 选择窗口时列表按“最后焦点时间”优先排序（最近活跃优先）。

### 2.2 番茄钟（基于队列，不含固定休息段）
- 计时单位来自“队列项时长”，不再使用全局专注/休息时长。
- 队列支持：
  - 从专注事项添加
  - 修改每项时长
  - 删除项
- 循环次数 `<= 0` 表示无限循环；否则按次数循环后进入下一项。
- 到点行为：系统通知 + 到点提示音（可在设置里选声音与音量倍率）。
- 提供开始、暂停、重置、跳过。

### 2.3 偏离检测
- 仅当当前队列项配置了窗口组时启用偏离检测；未配置则明确显示“不检测偏离”。
- 偏离判断已支持“精确窗口 + 手动规则”两种匹配方式，不再只依赖 `classificationKey` 精确比对。
- 偏离模式支持单按钮切换：
  - 连续：回到目标窗口后偏离计时清零。
  - 累计：回到目标窗口后保留累计偏离时长。
- 偏离阈值（分钟）可配置；达到阈值触发一次提醒（通知 + 偏离提示音）。
- 计时使用毫秒级时间差累计，减少定时器漂移造成的偏差。

## 3. 时钟

### 3.1 秒表
- 精度：0.01 秒。
- 功能：开始、暂停、断点、重置、结束并保存。
- 每个断点记录：
  - 断点时刻
  - 相对上一条增量
  - 备注（可编辑）

### 3.2 秒表记录
- 列表展示每次秒表会话（可重命名、删除、查看详情）。
- 默认记录名：`开始时间 - 结束时间`。
- 删除需要二次确认。

### 3.3 秒表记录详情
- 可继续编辑记录名和每个断点备注。
- 右上角“复制”支持三种格式：
  - 复制纯文本
  - 复制 Markdown 格式
  - 复制表格格式（制表符，适合粘贴到 Excel）
- 备注为空时按空字符串输出，不会自动写“无”。

### 3.4 倒计时
- 可创建多个倒计时任务（名称、时长秒数）。
- 每条任务支持开始/暂停、改时长、应用修改、删除。
- 到点后行为由“设置 > 通用配置”决定：
  - 保留并划线（点击卡片可删除）
  - 完成即删除
- 到点会触发系统通知和“倒计时到点提示音”。

## 4. 计算器

### 4.1 算数计算机（当前已实现）
- 支持实时表达式计算，输入更新后立即返回结果。
- 支持运算：`+ - * / % ^`、括号、前后置正负号。
- 支持常量：`pi`、`e`（也支持输入 `π`）。
- 支持函数：`log`、`ln`、`lg`、`sqrt`、`abs`。
- 可返回以下结果类型：
  - 正常数值结果
  - `NaN`
  - “除数不能为零”
  - “式子不合法”
- 输入一元方程（包含 `=`，未知数为 `x`）时可自动求解：
  - 对可识别的二次及以下多项式方程给出实数解全集
  - 对一般方程给出扫描范围内的近似实数解
  - 无解时给出无解提示

## 5. 数据统计

- 顶部可切换展示维度：`显示性质` / `显示窗口`。
- 可选统计日期（默认今天）。
- 页面展示当前焦点窗口（实时）。
- 数据统计页按焦点时长统计；只打开但没有获得焦点的对象，请在“进程管理”中查看。
- 图表包含：
  - 扇形图：选定日期分布，性质模式会列出全部固定性质，0 时长也会显示
  - 柱状图：焦点时长排行，窗口模式按设置中的数量 n 显示最高的 n 个窗口
  - 趋势图：近 14 天总聚焦时长 + 每个性质或窗口的聚焦时长；窗口模式按近 14 天总聚焦时长显示前 n 个窗口
  - 小时活动：性质模式按性质堆叠，窗口模式按当天焦点时长前 n 个窗口堆叠，也可切换总量
  - 时间线：最近 12 小时会话 + 开关机事件
  - 热力图：近 30 天，按分类查看每日时长深浅

## 6. 键鼠统计

- 页面入口：左侧栏“键鼠统计”。
- 采集范围：键盘按键次数、鼠标左/右/中键点击、侧键点击、滚轮滚动量、鼠标移动距离。
- 归因方式：键鼠事件会归入当前焦点窗口对应的 `classificationKey`，与进程时间统计使用同一套窗口识别结果。
- 记录阈值：键鼠记录和窗口记录共享“记录阈值”。窗口达到阈值前只在内存中缓存键鼠活动，达到阈值才写入；窗口未达到阈值就关闭时缓存会被丢弃。
- 隐私边界：软件不保存输入内容、具体按键文本、鼠标坐标或点击位置，只保存聚合数量和移动距离。
- 数据存储：键鼠累计数据和 10 分钟时间桶写入 SQLite 数据库 `kewu-toolbox.sqlite`。
- 页面状态：统计日期和当前选择的指标会保留，切换页面后再回来不会重置。
- 图表包含：
  - 今日指标卡：按键、点击、滚动、鼠标移动
  - 窗口排行：按当前选择指标从高到低排序
  - 窗口占比：按当前选择指标显示扇形图
  - 最近 12 小时活动：按窗口堆叠显示当前指标
  - 明细表：展示窗口、类型、今日焦点时长、键鼠指标和最后输入时间
- 权限说明：普通权限运行时，Windows 可能无法捕获管理员权限程序中的键鼠事件；如需统计这类窗口，需要让 KewuToolbox 以相同权限运行。

## 7. 待办列表与归档

### 7.1 待办列表
- 新建待办卡片，支持搜索与类型筛选。
- 任务类型：
  - 一次性
  - 重复（每日/每周/每月/自定义模式）
- 自定义模式格式示例：`0,2,3,1,-1`（执行/跳过交替，末尾 `-1` 表示循环）。
- 定时提醒支持“年/月/日可空 + 时分秒必填”：
  - 年空：每年该月日提醒
  - 月空：该年每月该日提醒
  - 日空：该年该月每天提醒

### 7.2 待办详情
- 点击卡片进入详情页。
- 可修改标题、提醒开关与提醒时间。
- 可编辑“心得记录”，输入后立即写入数据，界面状态短暂显示保存中/已保存，防止切页丢失。

### 7.3 完成与归档
- 勾选待办即完成，生成归档记录（包含心得快照和任务 JSON 快照）。
- 一次性任务：标记归档后不再出现在待办列表。
- 重复任务：完成后心得会清空，进入下一轮时为新心得。

### 7.4 归档列表与详情
- 按任务分组显示归档次数和最近完成时间。
- 进入详情可查看每次完成记录和快照。
- 删除归档组需要二次确认，且会清理已归档的一次性任务残留。

## 8. 设置

### 8.1 通用配置
- 记录阈值（秒）：窗口累计可见时长达到阈值才写入统计。
- 数据统计窗口数量 n：数据统计切换到窗口模式时，图表只展示最高或最近的 n 个窗口，默认 10。
- 主题切换：暗色 / 亮色。
- 开机自启动：桌面版可用（写入系统登录项）。
- 倒计时完成后处理方式：保留划线 / 完成即删。
- 数据目录路径：
  - 显示当前数据目录和 SQLite 数据库路径
  - 支持手动输入或文件选择器
  - 目标不存在时可弹窗确认“创建新数据目录并切换”
- 数据库：
  - 显示 SQLite 文件大小、焦点记录、进程时间线、键鼠时间线和配置片段数量
  - 提供“从旧 JSON 迁移”按钮，用于把旧版 `app-state.json` 或分片 JSON 写入 SQLite
- 白名单规则（支持通配符）：
  - 字段与黑名单一致：名称 / 类型 / 进程
  - 多一个“命名”字段，用于把命中对象重命名并归并统计
  - 命中白名单的对象不会再以原对象名单独记录
  - “按白名单归并记录”按钮会按照当前白名单重新处理已有历史记录、统计、时间线、标签绑定、专注事项窗口组和当前运行缓存
  - 同一历史对象命中多条白名单时，会复制归入多个白名单统计项
- 进程黑名单（支持通配符）：
  - 可按名称/类型/进程任意组合匹配
  - 同一规则中填写的字段需同时匹配才忽略
  - 进程管理页点击“屏蔽”会自动新增对应黑名单规则
  - 默认包含 `explorer.exe` 的黑名单规则（可手动删改）
- 清除所有数据：二次确认后清空本地全部业务数据。

### 8.1.1 页面输入状态保留
- 设置页未提交的提示音路径、白名单/黑名单新增输入、数据路径、记录阈值输入会在切换页面后保留。
- 待办列表的新建表单、搜索词、筛选条件会保留。
- 专注事项的新建/编辑弹窗、标题、时长、已选窗口、手动规则输入会保留。
- 数据统计页的日期、热力图类别、小时图模式会保留。
- 键鼠统计页的日期和指标切换会保留。
- 进程管理标签页的新建/编辑标签输入会保留。
- 删除确认、拖拽状态、批量删除勾选等危险或瞬时交互状态不会跨页面保留。

### 8.2 插件管理
- 提供官方插件下载入口（按当前软件版本号拼接 Release 下载链接）。
- 显示“已连接插件”列表（名称、ID、版本、协议版本、记录数、最近上报时间）。
- 列表信息由插件实时上报，心跳超时后自动移除。

### 8.3 软件更新
- 提供 GitHub 仓库首页入口。
- 支持读取 GitHub Releases 最新正式版本并和当前版本比较。
- 发现新版本后显示版本、便携版 exe、`.sha256` 校验文件和发布说明。
- 便携版可点击“开始更新”：主程序会先下载新版 exe 和 `.sha256` 并显示进度，校验通过后再交给更新脚本关闭主程序、替换 exe 并重启。
- 若 Release 缺少便携版 exe 或 `.sha256`，不会执行自动更新，只能手动打开发布页下载。

### 8.4 提示音管理
- 可配置三类事件声音：
  - 番茄钟到点
  - 偏离提醒
  - 倒计时到点
- 每类可选择“无”（不播放）或选择已有声音文件。
- 每类可设置事件音量倍率（无上限）。
- 声音库管理：
  - 新增声音（系统文件选择器 / 手动路径）
  - 改名、改路径、改默认倍率
  - 点击行或“试听”按钮试听
  - 删除声音（若被事件引用会自动回退到其他可用声音）
- 内置两条默认声音文件（到点、偏离）会自动存在于声音库。

## 9. 插件系统（Plugin Bridge）

- 目录：`browser-extension/`、`vscode-extension/`
- 官方浏览器插件版本：`1.0.4`
- 官方 VS Code 工作区插件版本：`1.0.4`
- 插件版本不跟随主程序版本自动同步；每个插件目录必须维护 `COMPATIBILITY.md` 版本兼容表，说明各插件版本兼容哪些 KewuToolbox 版本。
- 统一上报地址：`http://127.0.0.1:17321/plugin-bridge`
- 支持上报：
  - 插件元信息（用于设置页展示）
  - 记录列表（替代对象）
  - 抑制规则（抑制原生进程）
  - 焦点对象键或焦点对象键数组（用于焦点计时；多条白名单同时命中时可重复计入）
- 第三方插件接入规范见：
  - [插件接入规范](./插件接入规范.md)
