# KewuToolbox v2.2.0

本版本新增剪贴板工具，并完善剪贴板历史的持久化、事件监听和去重机制。

## 新增

- 新增“剪贴板”页面，包含“信息显示”和“剪贴板”两个子页面。
- 文本剪贴板支持显示总字数、不含标点字数，并可编辑后重新复制。
- 图片剪贴板支持显示尺寸、类型、估算大小、剪贴板格式和图片预览。
- 图片支持长按取色，显示 RGB、RGBA、HEX、HEX8、`0xRRGGBBAA`、HSL 等颜色格式，并可点击复制颜色值。
- 新增剪贴板历史列表，文本和图片历史项可点击重新写入系统剪贴板。

## 优化

- 剪贴板历史改为写入 SQLite 的 `clipboard_history` 表，重启软件后仍可保留。
- Windows 下新增 Rust 原生剪贴板监听组件，通过 `AddClipboardFormatListener` 接收系统剪贴板变化事件。
- 原生监听组件不可用时会自动退回兼容轮询，避免剪贴板功能失效。
- 剪贴板历史按内容签名去重，并记录重复出现次数。
- 忽略短时间内由 KewuToolbox 自己写入剪贴板触发的重复事件，避免点击历史项后再次产生重复记录。
- 剪贴板页面订阅主进程推送事件，复制内容变化后可以更及时刷新。
- 图片取色时按住图片滚轮只调整放大倍率，不再同时触发页面滚动。

## 设置与构建

- 设置页“数据库”状态中新增剪贴板历史数量。
- 新增 `npm run build:clipboard-listener`，用于单独编译 Windows 原生剪贴板监听组件。
- Windows 开发模式、启动和打包流程会自动编译剪贴板监听组件。
- Windows 打包产物会携带 `resources/native/kewu-clipboard-listener.exe`。

## 说明

- 本功能读取的是当前系统剪贴板，并由 KewuToolbox 自行保存历史。
- Windows 系统 Win+V 历史没有稳定的 Electron 读取接口，因此本版本不直接读取系统 Win+V 历史列表。
