KewuToolbox v2.4.0

本版本为待办事项增加定时关机功能，并提高定时任务在后台运行时的可靠性。

新增

- 待办事项开启定时后，可选择“定时提醒”或“定时关机”。
- 新建待办和待办详情页均可修改到点执行动作。
- 待办卡片会显示当前定时动作及执行时间。
- 定时关机会在到点后调用 Windows 系统关机功能。

优化

- 托盘隐藏时继续保持待办、番茄钟等秒级计时任务运行。
- 定时任务增加 10 秒触发宽限，降低主线程短暂卡顿导致漏触发的概率。
- 同一时刻存在多个定时关机任务时，只执行一次系统关机命令。
- 关机前同步保存任务触发标记，避免重复执行。

兼容性

- 旧版本待办数据无需迁移；缺少动作类型的定时任务默认按“定时提醒”处理。
- 数据库结构未变，兼容 v2.3.2 数据。
