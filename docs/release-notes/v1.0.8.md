KewuToolbox v1.0.8

本版本重点修复归档记录兼容显示问题，并重构键鼠统计页面的信息结构。

修复
- 修复新版分片数据目录与旧版单文件数据共存时，缺失分片没有从旧 `app-state.json` 补迁移的问题。
- 归档列表和归档详情兼容旧数据：如果旧版本只保存了 `isArchived` 的待办而没有 `archives` 记录，页面也会按只读归档记录显示。
- 归档页面恢复正常中文文案，并增强空状态说明。

优化
- 重构“键鼠统计”页面，取消按键、点击、滚动、移动四类重复页面式布局。
- 新页面改为参考统计面板结构：今日统计、鼠标点击明细、按键分布、活跃应用、历史趋势、窗口明细。
- 历史趋势支持 7 天/30 天切换，并可切换点击、按键、移动、滚动指标。
- 保留隐私策略：当前仍只保存聚合数量，不保存具体按键文本、输入内容、鼠标坐标或点击位置。

版本
- 项目版本号升级至：1.0.8
- 官方浏览器插件版本保持：1.0.4
- 官方 VS Code 工作区插件版本保持：1.0.4
