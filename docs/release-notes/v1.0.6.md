KewuToolbox v1.0.6

本版本新增键鼠统计能力，将按键、鼠标点击、滚轮和鼠标移动数据接入原有窗口识别与统计体系。

新增
- 新增全局键鼠采集：按当前焦点窗口记录按键次数、鼠标点击次数、滚轮滚动量和鼠标移动距离。
- 新增“键鼠统计”页面。
- 页面包含今日指标卡、窗口排行、窗口占比、最近 12 小时活动图和窗口明细表。
- 键鼠统计页支持日期选择和指标切换：按键、点击、滚动、移动。
- 新增键鼠数据文件：`input-activity-stats.json`、`input-activity-timeline.json`。

优化
- 键鼠数据与原有窗口识别结果共用 `classificationKey`，可与浏览器插件、VS Code 插件、白名单归并结果保持一致。
- 键鼠记录共享“记录阈值”：未达到阈值的临时窗口只做内存缓存，达到阈值才写入；未达到阈值就关闭的窗口不会进入键鼠统计。
- 删除进程记录、白名单归并时会同步处理键鼠统计数据。
- 侧边栏文字恢复为正常中文显示，并新增“键鼠统计”入口。

隐私说明
- 软件只保存聚合数据，不保存输入内容、具体按键文本、鼠标坐标或点击位置。
- 如果焦点落在管理员权限程序上，普通权限运行的 KewuToolbox 可能无法捕获对应键鼠事件。

- 官方浏览器插件版本保持：1.0.4
- 官方 VS Code 工作区插件版本保持：1.0.4
