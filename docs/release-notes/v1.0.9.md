KewuToolbox v1.0.9

本版本补齐键鼠统计页面中的占位功能，并扩展键盘按键分布数据。

新增
- 新增键盘热力图：按物理按键显示当日按键次数，颜色越深表示次数越多。
- 新增按键排行模式：可在热力图和排行之间切换。
- 新增应用统计详情：活跃应用区域可展开明细表，查看每个窗口的聚焦时长、按键、点击、滚动、移动和最后输入时间。
- 历史记录新增折线图/柱状图切换。

数据
- 键鼠统计数据新增 `keyCounts` 字段，按 `uiohook-napi` 的物理 `keycode` 聚合记录每个按键次数。
- 旧版本数据兼容：没有 `keyCounts` 的旧记录会按空按键分布处理，不影响已有按键总数、点击、滚动和移动统计。

优化
- 移除键鼠统计页多余的说明文字。
- 移除原先不可点击的“键盘热力图”“应用统计详情”占位按钮。

版本
- 项目版本号升级至：1.0.9
- 官方浏览器插件版本保持：1.0.4
- 官方 VS Code 工作区插件版本保持：1.0.4
