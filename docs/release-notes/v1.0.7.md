KewuToolbox v1.0.7

本版本重点修复便携版开机自启动失败的问题。

修复
- 修复 Windows 便携版开启“开机自启动”后无法在开机时启动的问题。
- 原因是 Electron 便携版运行时会解包到临时目录，旧逻辑把 `%TEMP%` 中的 `KewuToolbox.exe` 写入了启动项；这些临时路径重启后会失效。
- 现在 Windows 自启动改为直接写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，并优先使用 `PORTABLE_EXECUTABLE_FILE` 指向的真实便携版 exe。
- 启用或同步自启动设置时，会清理旧的 `electron.app.Electron`、`electron.app.KewuToolbox` 错误启动项，避免残留失效路径干扰。

版本

- 官方浏览器插件版本保持：1.0.4
- 官方 VS Code 工作区插件版本保持：1.0.4
