KewuToolbox v1.0.2

本版本重点优化了数据统计页面的排行图显示，并完善了 GitHub Actions 自动发布说明能力。

新增
- 新增按版本维护的 Release notes 机制。
- 发布时会优先读取 `docs/release-notes/v<版本>.md`，用于展示详细更新信息。
- 如果版本说明中没有 `Full Changelog:`，发布流程会自动追加上一版本到当前版本的对比链接。

优化
- 优化数据统计页面“焦点时长排行”图表布局。
- 减少排行图左侧无效留白。
- 窗口名称限定在固定显示范围内。
- 长名称会按中英文宽度估算后自动截断。
- 名称越长字号会自动变小，避免标签互相重叠。
- 调整排行图每一行高度，使多条记录显示更规整。
- 调整左侧页面列表顺序，将“进程管理”和“计算器”互换位置。

版本
- 项目版本号升级至：1.0.2
- 官方浏览器插件版本升级至：1.0.2
- 官方 VS Code 工作区插件版本升级至：1.0.2
