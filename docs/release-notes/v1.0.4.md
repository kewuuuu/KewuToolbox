KewuToolbox v1.0.4

本版本重点优化 Windows 打包后的程序显示信息，让任务管理器和文件属性中更稳定地显示软件名称与图标。

优化
- Windows 打包配置新增 `executableName: KewuToolbox`，确保生成的主程序文件名和内部可执行名称保持一致。
- Windows 打包配置开启 `signAndEditExecutable`，允许 electron-builder 写入 exe 资源信息。
- 打包后的 exe 会写入产品名、文件描述、版本号和软件图标，减少任务管理器显示为 Electron 的情况。

说明
- Electron 仍然会保留 Chromium 多进程模型，任务管理器中可能展开多个子进程，这是正常行为。
- 本次修改改善的是进程显示名称、图标和文件属性，不会减少 Electron 子进程数量。
- 官方插件版本从本版本开始不再要求和主程序版本同步；每个插件目录新增兼容表说明插件版本与主程序版本的对应关系。

版本
- 项目版本号升级至：1.0.4
- 官方浏览器插件当前版本：1.0.4
- 官方 VS Code 工作区插件当前版本：1.0.4
