KewuToolbox v2.3.1

本版本修复 SQLite 存储优化后导致统计数据不显示的问题。

修复

- 修复数据统计页面焦点数据、键鼠数据为空的问题。
- 修复 SQLite 查询游标未完全释放，导致后续写入反复报错 `This database connection is busy executing a query` 的问题。
- 修复统计缓存为空或过期时不会自动恢复的问题。
- 修复进程管理汇总缓存失效后可能反复重算的问题。

优化

- 数据统计读取前会自动检查焦点每日缓存和键鼠每日缓存，缺失时自动重建。
- 缓存重建失败时会回退到原始 SQLite 表即时聚合，避免页面空白。
- 进程管理汇总缓存失效时会自动重建，失败时才回退到即时聚合。

兼容性

- 数据库结构未变，兼容 v2.3.0 数据。
