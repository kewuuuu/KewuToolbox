KewuToolbox v1.0.5

本版本重点修复便携版自动更新过程中的临时文件命名和替换时机问题。

修复
- 修复从旧版本更新时，下载临时文件仍使用旧 exe 文件名的问题。
- 修复更新脚本只等待主进程退出，未等待 Electron 子进程释放 exe 文件，可能导致替换失败的问题。
- 更新脚本现在会等待目标 exe 解锁后再备份和替换。

优化
- 更新下载临时文件会优先使用 Release 资产名，例如 `KewuToolbox-1.0.5-portable.exe.download`。
- 若用户手动改过 exe 文件名，更新器仍会替换当前正在运行的 exe 路径，避免更新后启动入口变化。

说明
- 如果软件放在 `Program Files` 等受保护目录，仍可能需要管理员权限。
- 如果软件同目录已经能生成 `.download` 文件，一般说明目录写入权限存在，替换失败更可能是 exe 仍被进程占用。
- 官方插件版本本次不变，仍按各插件目录的 `COMPATIBILITY.md` 维护兼容范围。

版本
- 项目版本号升级至：1.0.5
- 官方浏览器插件当前版本：1.0.4
- 官方 VS Code 工作区插件当前版本：1.0.4
