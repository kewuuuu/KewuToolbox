# KewuToolbox v2.0.0

本版本将主数据存储从 JSON 升级为 SQLite，重点提升长期使用时的数据组织能力和按时间范围查询的基础能力。

## 新增

- 新增 SQLite 数据库文件：`kewu-toolbox.sqlite`。
- 新增设置页“数据库”子页面：
  - 显示数据目录与 SQLite 文件路径。
  - 显示数据库大小、焦点记录、进程时间线、键鼠时间线和配置片段数量。
  - 提供“从旧 JSON 迁移”按钮，可把旧版 `app-state.json` 或分片 JSON 写入 SQLite。

## 调整

- 焦点时间线、进程时间线和键鼠时间桶改为独立 SQLite 表，并建立时间索引。
- 配置、待办、番茄钟、提示音、页面状态等小型状态写入 SQLite 的配置片段表。
- 旧 JSON 文件会保留，不会在迁移时自动删除。

## 兼容

- 首次启动 v2.0.0 时，如果当前数据目录没有 SQLite 数据但存在旧 JSON 数据，会自动迁移。
- 如果需要手动重新迁移，可进入“设置 > 数据库”执行。
- 手动迁移入口计划只保留一个大版本，后续大版本会移除旧 JSON 迁移功能。
- 因主存储格式改变，本版本按大版本升级为 `2.0.0`。
