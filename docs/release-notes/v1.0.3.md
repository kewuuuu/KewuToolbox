KewuToolbox v1.0.3

本版本重点重构便携版自动更新流程，让下载过程可视化，并降低隐藏更新脚本失败风险。

新增
- 新增自动更新下载进度显示。
- 新增更新阶段提示：准备、下载新版、下载校验文件、校验、准备替换、启动更新程序。
- 新增主进程更新进度事件，设置页面可实时显示下载百分比和文件大小。

修复
- 修复旧更新流程在隐藏 PowerShell 中下载失败时用户不可见的问题。
- 修复主程序开始更新后过早关闭导致无法展示下载状态的问题。
- 修复更新脚本依赖下载链接重新下载导致的失败风险。

优化
- 主程序负责下载新版 exe 和 SHA256 校验文件，校验成功后才调用更新脚本。
- 更新脚本只负责等待/关闭主程序、替换 exe、重启软件。
- 更新失败时主程序保持打开并显示错误信息。

版本
- 项目版本号升级至：1.0.3
- 官方浏览器插件版本升级至：1.0.3
- 官方 VS Code 工作区插件版本升级至：1.0.3
